ScoreBreak v5

Jordan Hendry·January 4, 2022

An ode to professional coaches, Version 5 extends upon ScoreBreak's foundation with powerful new features and functionalities. v5's marquee feature is Tag Boards, which offer the ability to program an interactive panel of tags with customizable actions and outcomes. The new Reports feature allows data to be visualized and optionally exported. Additional new functionalities include the ability to recover recently deleted items, personalize your workspace by uploading your team logo, and view trends and tendencies with a new data visualization tool.

Tag Boards enable a user to set up an interactive cutting and tagging interface to match their needs, with the ability to chain a sequence of individual boards into focused, logical workflows.

Tag Board Buttons can be configured as:

  • Recordable Clips: press twice to start and finalize a clip recording
  • Droppable Pins: one press creates a clip with predefined lead and lag times
  • Tag Labeling: adds a tag to a pre-selected clip

Advanced options include Lead/Lag time adjustment, custom hotkeys, linked tag boards, and show count.

The Reports feature includes Stats Reports and Data Reports. Default Data Reports include Staff Clips Data, Roster Clips Data, All Tagged Data, and Tagged Game Stats Data. Every component of a report is interactive — selecting a numerical value returns the list of video clips that make up that count. Report data can be exported to CSV.

Version 5 also features a new dark app icon, new animations for tapping gestures on the video player, timeline resizing on Mac, and numerous iterative improvements.

ScoreBreak v5 is available for download on the App Store and Mac App Store.
