ScoreBreak Web App v4 is an update focused on power user tools for content creation and advanced editing interactions. Workflows once found only on ScoreBreak native applications for iPad, iPhone, and Mac have been added to version 4 of the Web App — providing greater consistency for coaches and athletes using Chromebooks, PCs, or other devices.

The ability to create Clips is being officially announced in version 4, along with the ability to interact with elements via drop down contextual menus enabling sharing via Chat, adding Clips to Playlists, adjusting Clip time ranges, and more.

Clips can be created as a Recordable Clip or a Droppable Pin. Recordable Clips allow you to define exact start and end times. Droppable Pins create a 15 second Clip automatically — 12 seconds prior to the current video time and 3 seconds after — in one click. The <kbd>P</kbd> key on a keyboard will drop a pin.

Playlists now support creating and editing Title Cards, Clip Notes, and rearranging Clips via drag-and-drop. Sharing Playlists, Games, and Clips via Chat surfaces content directly to your athletes, reducing the friction of having to find it themselves.

Additional features in v4 include the ability to nudge film to live-stats for precision alignment, custom team logo support, and a host of performance enhancements.
