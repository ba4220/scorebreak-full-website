Staying in communication is instrumental to your team's development, organization, and performance. ScoreBreak provides partner teams with a premier chat functionality to help connect coaching staffs with their athletes in today's digital-first environment. ScoreBreak released updates to the native (iPhone, iPad, Mac) and web applications on June 1, 2022.

These updates reenergize the Chat interface with an all new design, adding customization options to enhance chat room personalization, and set the stage for deeper insights into who has seen what.

ScoreBreak Chat v2's design refresh is centered on meeting currently accepted messaging application standards — vibrant colors, a chat-message-bubble design paradigm, and flexibility to provide interface customizations. Features include emoji reactions, the ability to share photos and files, and animated gif support.

The bubble message design provides a clear target to interact with. Tapping and holding, or right-clicking on the Mac, provides a context menu with message options and the ability to add message reactions. The Message Analytics view displays who has reacted to a message, and in an upcoming release will expand to include statistics on who has seen the message.

Files, photos, videos, animated gifs, and ScoreBreak content can all be shared as attachments.

<blockquote>"There is a sense of professionalism when you enter ScoreBreak app," one coach noted, "it's certainly useful, but it's kind of like practice: when you are in there, you are in there for a job."</blockquote>

Find the updated Chat system in ScoreBreak versions 5.1 for iPad, iPhone, and Mac, and Web App version 4.1.
